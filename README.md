# Pig Dodge 🐷
Pig Dodge is a lightweight, addictive 2D survival game developed for Android. The premise is simple but challenging: you play as a pig trapped in a falling-block zone. Your only goal is to move quickly and avoid being crushed to achieve the highest score possible.

# 🎮 Gameplay Features

Mobile-Optimized Controls: Simple touch-based movement designed for a smooth experience on Android devices.


Clean 2D Aesthetics: Minimalist graphics for clear visibility and high-performance gameplay.

# 🛠️ Technical Specifications
Game Engine: Unity 2022.3.46f1 (LTS)

Platform: Android

Language: C#

Rendering: 2D Sprite-based workflow

# 🚀 How to Play

Simply download the Pig Dodge.apk present in the repository and install it on your android device and enjoy!!!
